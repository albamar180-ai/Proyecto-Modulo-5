# Proyecto Modulo 5 - Alke Wallet

**Estudiante:** Alba Moreno  
**Bootcamp:** Full Stack Python

Proyecto de base de datos relacional para una wallet virtual.

## Contenido

- `sql/AlkeWallet.sql`: creación de base de datos, tablas, claves, datos de prueba y consultas.
- `docs/Proyecto_Modulo_5_Alke_Wallet_Alba_Moreno.docx`: documento entregable.
- `docs/modelo_entidad_relacion.md`: modelo entidad-relación explicado de forma simple.
- `capturas/`: carpeta que guarda las capturas obtenidas al ejecutar el script en SQLOnline/MySQL.

## Cómo probar

1. Abrir https://sqliteonline.com/ y seleccionar **MySQL 8**.
2. Copiar el contenido de `sql/AlkeWallet.sql`.
3. Ejecutar primero `CREATE DATABASE`, `USE` y los `CREATE TABLE`.
4. Ejecutar los `INSERT`.
5. Ejecutar los `SELECT`, `UPDATE` y `DELETE` por separado.
